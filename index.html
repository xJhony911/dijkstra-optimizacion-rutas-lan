El Algoritmo de Dijkstra

Método voraz (greedy) para hallar el camino mínimo en grafos ponderados con pesos no negativos. Base matemática de protocolos de enrutamiento reales como OSPF.

01

Inicialización

d[s]=0, d[v]=∞ para todo v≠s. Cola de prioridad Q contiene todos los vértices. π[v]=NULL (predecesores).

02

Extracción Mínima

u ← EXTRAER-MIN(Q). El nodo con menor distancia tentativa. Con heapq esto cuesta O(log V) por extracción.

03

Relajación

Si d[v] > d[u] + w(u,v) entonces d[v] = d[u] + w(u,v), π[v] = u. Se actualiza solo si encontramos camino más corto.

04

Convergencia

Al extraer u de Q su distancia d[u] es ya definitiva (pesos no negativos garantizan invariante de bucle).

05

Reconstrucción

Recorrido inverso del arreglo π[] desde destino hasta origen para reconstruir la ruta óptima P*.

06

Complejidad O((V+E)logV)

Para V=8, E=11: ≈ 57 ops. Bellman-Ford necesita O(VE)=88. Dijkstra es 35% más eficiente en esta red.

O((V+E) log V)
Dijkstra con heapq
(8+11)·log₂(8) ≈ 57 ops
O(VE)
Bellman-Ford (comparación)
8 × 11 = 88 ops
O(V²)
Dijkstra con arreglo simple
8² = 64 ops
≈ 0.0001 s
Tiempo de ejecución real
medido con time.perf_counter()

# main.py — Implementación del algoritmo de Dijkstra
# ESPOCH · Matemática Avanzada · Grupo 1 · 2026

import heapq
from grafo_lan import grafo

def dijkstra(grafo, origen):
    # Inicialización: d(v)=∞ para todos los vértices
    distancias = {nodo: float('inf') for nodo in grafo}
    # π(v)=NIL — vector de predecesores
    predecesores = {nodo: None for nodo in grafo}
    # Distancia del nodo origen
    distancias[origen] = 0
    cola = [(0, origen)]  # min-heap: (costo, nodo)

    while cola:
        distancia_actual, actual = heapq.heappop(cola)
        for vecino, peso in grafo[actual].items():
            # Relajación: d[v] > d[u] + w(u,v)
            nueva_distancia = distancia_actual + peso
            if nueva_distancia < distancias[vecino]:
                distancias[vecino] = nueva_distancia
                predecesores[vecino] = actual
                heapq.heappush(cola, (nueva_distancia, vecino))

    return distancias, predecesores

def reconstruir_ruta(predecesores, destino):
    ruta = []
    while destino:
        ruta.append(destino)
        destino = predecesores[destino]
    ruta.reverse()
    return ruta

# ─── Programa principal ───────────────────────────────
origen = 'A'
destino = 'H'

distancias, predecesores = dijkstra(grafo, origen)
ruta = reconstruir_ruta(predecesores, destino)

print("=" * 50)
print("ALGORITMO DE DIJKSTRA")
print(f"Origen : {origen}")
print(f"Destino: {destino}")
print(f"Ruta óptima: {' → '.join(ruta)}")
print(f"Costo total: {distancias[destino]} ms")
print("=" * 50)

# visualizacion.py — Visualización con NetworkX y Matplotlib
# Validación cruzada: compara implementación propia vs NetworkX
# ================================================================
import networkx as nx
import matplotlib.pyplot as plt
from grafo_lan import grafo

# Construir grafo NetworkX desde el diccionario
G = nx.Graph()
for nodo in grafo:
    for vecino, peso in grafo[nodo].items():
        G.add_edge(nodo, vecino, weight=peso)

# Layout y visualización base
pos = nx.spring_layout(G, seed=42)
nx.draw(G, pos, with_labels=True, node_size=2500)
etiquetas = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, edge_labels=etiquetas)

# ── Validación cruzada ────────────────────────────────
print("Validación NetworkX:")
for destino in ['B','C','D','E','F','G','H']:
    ruta_nx = nx.dijkstra_path(G, 'A', destino, weight='weight')
    costo_nx = nx.dijkstra_path_length(G, 'A', destino, weight='weight')
    print(f"A→{destino}: {' → '.join(ruta_nx)} | {costo_nx} ms")

plt.title("Topología LAN del Proyecto")
plt.show()
